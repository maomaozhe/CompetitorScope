# 本地 Web 页面设计

日期：2026-09-28

## 目标

为独立的 `repo_research_poc` 提供可在本机浏览器使用的入口：显式输入快照目录、Commit SHA 和问题，查看运行状态、回答、有效代码引用、未解决问题与历史审计记录。

## 方案

采用 Python 标准库 HTTP 服务和静态 HTML/CSS/JS，复用现有 `run_research`。服务仅绑定 `127.0.0.1`，模型配置与密钥从启动环境读取；浏览器不接收或提交密钥。一次只运行一个任务，后台线程执行，前端轮询任务状态。历史记录只从配置的输出目录读取 `32` 位十六进制 ID 命名的 JSON 文件。

API 为 `POST /api/jobs`、`GET /api/jobs/{id}`、`GET /api/runs`、`GET /api/runs/{id}`。输入先经现有 `validate_request` 检查，输出目录必须在快照之外。页面只展示 `status=ok` 的回答和引用；失败时展示错误、引用问题、解析尝试和工具调用，不把未验证回答当成结果。

## 验证

使用 pytest 通过真实本地 HTTP 请求验证输入校验、后台任务、历史记录读取、路径 ID 限制和失败结果隐藏；浏览器检查桌面与窄屏布局，并保存不含私有源码的截图。
